## Task 1: Exploratory Data Analysis on Retail Sales Data

### Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on retail sales data to identify sales patterns, customer behaviour trends, product category performance, and actionable business insights.

### Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Analysis Performed

The following analyses were performed:

1. Dataset shape and structure analysis
2. Data type and missing value analysis
3. Duplicate value checking
4. Descriptive statistics
5. Monthly sales trend analysis
6. Customer age distribution analysis
7. Gender-wise sales analysis
8. Product category revenue analysis
9. Correlation analysis using a heatmap
10. Sales distribution by product category

### Key Findings

- Total revenue: ₹456,000
- Total quantity sold: 2,514 units
- Clothing had the highest sales quantity with 894 units.
- Electronics generated the highest revenue of ₹156,905.
- Average order value was ₹456.
- Female customers generated ₹232,840 in revenue.
- Male customers generated ₹223,160 in revenue.
- October 2023 recorded the highest visible monthly sales of ₹46,580.

### Business Recommendations

1. **Focus on Electronics:** Maintain sufficient inventory and promote high-value electronic products because Electronics generated the highest revenue.

2. **Promote Clothing:** Use discounts, bundles, and cross-selling offers to increase revenue from Clothing, which had the highest sales volume.

3. **Customer-focused Marketing:** Use purchasing behaviour and gender-wise sales patterns to create targeted marketing campaigns while continuing to serve all customer groups.

### Conclusion

The EDA provides useful insights into retail sales performance, customer behaviour, product categories, and monthly sales trends. The analysis can help businesses improve inventory planning, marketing strategies, and overall sales performance.
